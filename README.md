# Aligned HPO
Effective HPO for differentiable losses parameters.

## GraP
The implementation of GraP can be found at
[aligned-hpo/aligned_hpo/aligned_hpo.py](https://github.com/ivan-chai/aligned-hpo/blob/main/aligned_hpo/aligned_hpo.py)

Event Sequences experiments are implemented in the PreTPP repository:
[https://github.com/ivan-chai/pretpp](https://github.com/ivan-chai/pretpp)

Computer Vision experiments are implemneted in the fork of the solo-learn library (the ```corrhpo``` branch):
[https://github.com/ivan-chai/solo-learn/tree/corrhpo](https://github.com/ivan-chai/solo-learn/tree/corrhpo)
